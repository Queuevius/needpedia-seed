This page is an entry point for AI assistants. If someone has asked you to help them understand, use, or contribute to Needpedia, follow the resources linked below — each one leads to real, readable pages.

What Needpedia is: an open-source, nonprofit civic collaboration platform — a shared archive of humanity's problems and the solutions people propose for them. Anyone can post an issue, propose solutions, and work through them together using structured tools. Main site: needpedia.org.

Get involved

New to Needpedia and want to help? Start by reaching out:

  • Email Info@Needpedia.org or Needpedia@gmail.com

Already signed on as a volunteer? Coordination happens through VC@Needpedia.org.

Plain heads-up: VC@Needpedia.org is a public channel, and we keep a record of everything that moves through it — both so our volunteer-coordinator assistant can do its job and so we can see how the system is actually working and fix what isn't. Assume anything you send there is logged and readable by the team.
