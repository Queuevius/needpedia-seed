BOTSKILL: TAXONOMY NAVIGATION

== PURPOSE ==

Needpedia's goal is to organize all ideas for all problems with all

things — which only works if every idea lands in ONE findable place.

This skill defines how to navigate and grow the taxonomy without

creating duplicates, orphans, or clutter. It is written primarily for

Lotte (who creates and edits posts) but applies to any AI describing

where content belongs.

== THE PRIME DIRECTIVE ==

One concept, one post. Every duplicate splits a community in half.

When in doubt, attach to something existing rather than create

something new.

== SYNONYM RULE: "EARTH" ==

"Earth," "the world," "the planet," "humanity," "mankind," "everyone,"

"globally," and "civilization" all refer to the SAME subject: Earth.

Never create world/planet/humanity subjects — search for Earth and use

it. Apply the same synonym-collapsing logic everywhere: "USA" =

"United States" = "America"; "global warming" lives with "climate

change"; a city's nickname belongs with the city. Before creating any

post, mentally list 2-4 synonyms and search those too.

== SCOPE DECISION TREE ==

Ask: "Whose problem is this, at the smallest scale that still contains

the whole problem?"

1. Affects the whole planet or humanity as a whole (climate change,

pandemics, war as a phenomenon, extreme poverty globally) →

Subject: EARTH.

2. Affects a continent, region, or country → regional subject under

Earth (Earth > Africa; Earth > North America > United States).

Create intermediate levels only when needed.

3. Affects a specific place (city, neighborhood, school, park) → that

place as a subject, under its region. If it's a physical-space idea,

also suggest putting it on the map (geomaxxing).

4. Defined by a field or theme rather than a place → thematic subject:

Culture, Technology, Health, Environment, Politics, or a specific

subject like Poverty or Education.

5. About a community, movement, artwork, fandom, language, or practice

→ that thing is its own subject (e.g., "One Piece Fan Fiction,"

"Esperanto," "The Labor Movement").

6. About Needpedia itself → the Needpedia subject. Platform

self-improvement posts are welcome and encouraged.

Note: personal problems ("my back pain") are usually instances of

general problems ("Chronic Back Pain") — post the general form, which

helps the user AND everyone else with the same problem.

== PLACE vs THEME CONFLICTS ==

Many problems fit both a place and a theme ("Air pollution in Delhi":

Earth > Asia > India > Delhi? or Environment?). Rule: the PLACE wins as

primary home when the problem is about a specific place; the THEME wins

when the problem is about the phenomenon in general. Then

CROSS-REFERENCE: add a line in each related post linking to the other,

and use shared tags ("#AirPollution" on both). Cross-references are

cheap; duplicates are expensive.

== SEARCH DISCIPLINE (BEFORE EVERY CREATE) ==

1. Search the user's phrasing.

2. Search 2-4 synonyms and broader/narrower terms.

3. Search the would-be parent subject and skim its existing problems.

4. Found a match → link the user there; offer to help contribute

(comment, layer, token, or edit) instead of creating.

5. Found a NEAR match → prefer attaching (a new idea under the

existing problem; a token or layer on the existing idea) over a new

parallel post.

6. Nothing found → create, following the chain rule.

== CHAIN RULE ==

Subject → Problem → Idea, and parents before children. If a user

arrives with an idea, work backwards: what problem does it solve?

What subject holds that problem? Create only the missing links —

never recreate existing ones. Every post the AI creates should be

attached; orphan posts get lost.

== NAMING & TAGS ==

Titles: clear, descriptive, specific, self-contained — "Eradicating

Extreme Poverty Globally," not "My Big Idea" or "Poverty stuff."

A stranger should know what the post is about from title alone.

Tags: 3-6 per post, mixing one broad (#Health), one narrow

(#Malaria), and place tags where relevant (#Delhi). Reuse existing

tags rather than inventing variants (#ClimateChange, not

#Climate_Change2).

== DUPLICATE CLEANUP (when found after the fact) ==

If two posts cover the same concept: (1) tell the user; (2) treat the

older or more active post as primary; (3) with permission, add

cross-reference links between them and encourage consolidating

discussion in the primary; (4) never delete or gut someone else's

post — flag genuine merge cases for the team via Needpedia@gmail.com.

== HONESTY CLAUSE ==

The taxonomy is young and imperfect. When placement is genuinely

ambiguous, make the best call, cross-reference generously, and move

on — a slightly misfiled post that's cross-referenced is findable; a

perfect filing system that stalls users is not.
